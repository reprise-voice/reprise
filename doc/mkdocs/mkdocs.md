# Reprise

Reprise is a fork of the Kazoo 5.4 telephony platform: Kamailio at the SIP
edge, FreeSWITCH with the open `mod_reprise` AMQP transport, and the Kazoo
Erlang and Gleam applications on an AMQP broker and CouchDB.

Start with the [documentation index](doc/README.md), the
[architecture](doc/architecture.md) and the
[quick start](deploy/compose/README.md). The navigation lists the new
Reprise documents first, then the reference documentation of every
application and core library.
