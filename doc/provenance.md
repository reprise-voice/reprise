Everything else (`freeswitch/mod_reprise`, `tools/fs-contract-probe`,
`core/kazoo_gleam`, the Gleam applications, and the changes made to the
imported trees since their import) was written for Reprise and is
distributed under the MPL 2.0. `freeswitch/mod_reprise` also contains code
ported from FreeSWITCH and mod_kazoo, which are MPL 1.1.

2600Hz publishes erlang-amqp_dist and the kazoo-configs repositories
without a license file; their RPM packaging declares the configs as
MPL 1.1, and amqp_dist ships inside the MPL 2.0 Kazoo release packages
(`vendor/amqp_dist/NOTICE` records what is known). The dev-tooling
applications 2600Hz keeps separate (kazoo-ast, kazoo-properly) and the
4.x-only applications are not part of this tree.
